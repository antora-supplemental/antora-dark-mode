= Antora Dark Mode
:navtitle: Getting Started
:description: Dark mode supplemental UI for Antora documentation sites.

[IMPORTANT]
.Compatibility path: dark mode moved to antora-ui-chassis
====
This repository is the *antora-dark-mode 1.x compatibility path*. Dark mode now lives in https://github.com/antora-supplemental/antora-ui-chassis[antora-ui-chassis], and `antora-dark-mode` *2.x* on npm is published from there. It has the same name and installs the chassis packages `@antora-supplemental/color-scheme`, `@antora-supplemental/light-dark-mode` and `@antora-supplemental/default-paint`.

*Migrate (one line):*

[source,console]
----
npm i -D antora-dark-mode@2
----

[source,yaml]
----
antora:
  extensions:
    - require: antora-dark-mode
----

Remove the old `ui-bundle.zip`, `supplemental-ui` merge or `dark-mode` ui-module. Full guide: https://github.com/antora-supplemental/antora-ui-chassis/blob/main/docs/modules/ROOT/pages/migrate-dark-mode.adoc[Migrate from antora-dark-mode 1.x].

*Staying on 1.x?* Version 1.5.0 of this repository is an Antora extension (`lib/index.js`). It logs one warning per build that links the migration guide, then registers the same chassis packages that 2.x does. `localStorage` keys (`antora-theme-mode`), `html.dark-theme` and `data-theme` are unchanged. Not carried over: `themed-svg-element.js` and the VCS header partial.
====
