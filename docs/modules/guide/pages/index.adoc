= Antora Dark Mode
:navtitle: Getting Started
:description: Dark mode supplemental UI for Antora documentation sites.

[WARNING]
.Deprecated — merged into antora-ui-chassis
====
`antora-dark-mode` is *deprecated* and receives no further releases. Its light/dark mechanism (no-FOUC head hook, persistence, system preference, override expiry, crossfade, toggle behavior and accessibility) now lives in the chassis Antora extension https://github.com/antora-supplemental/antora-ui-chassis/tree/main/packages/color-scheme[`@antora-supplemental/color-scheme`]. The chassis package is *unstyled*: colors (paint) come from your theme, for example https://github.com/antora-supplemental/valentus-theme[valentus-theme] `css/site-paint.css`.

*Migrate:*

. Remove this overlay (`supplemental-ui` merge, `dark-mode` ui-module, or this repo's `ui-bundle.zip`).
. Add the extension pin: `"@antora-supplemental/color-scheme": "github:antora-supplemental/antora-ui-chassis#color-scheme-v0.1.2&path:packages/color-scheme"`
. Register it in the playbook:
+
[source,yaml]
----
antora:
  extensions:
    - require: "@antora-supplemental/color-scheme"
      toggle: auto   # or "placed" when your header renders #theme-toggle
----
. `localStorage` keys are unchanged (`antora-theme-mode`, legacy `antora-theme` is migrated).
. CSS hooks renamed: `html.antora-theme-animating` / `valentus-theme-*` → `html.color-scheme-animating` / `color-scheme-vt`. `html.dark-theme` and `data-theme` are unchanged.
. There is no default dark palette for the plain Default UI any more; supply your own paint or use Valentus.
====

Dark mode toggle, FOUC prevention, and CSS overrides for the Antora Default UI.

For composed doc-site chrome (mast, header, layout), see link:https://github.com/antora-supplemental/valentus-theme[valentus-theme].

Coming from the former **`antora-dark-theme`** package (or a personal fork of that name)? See xref:legacy-names.adoc[Legacy names & migration].
